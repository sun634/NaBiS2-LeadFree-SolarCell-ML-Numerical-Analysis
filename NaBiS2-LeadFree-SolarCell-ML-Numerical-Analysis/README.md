
# NaBiS₂ Lead-Free Solar Cell Numerical + ML Analysis

This repository contains numerical SCAPS-1D simulation and machine-learning-based performance
prediction of NaBiS₂ lead-free solar cells with varied hole transport layers (HTLs).

## 🔬 Research Focus
Numerical SCAPS-1D based device simulation and ML-driven performance
prediction of NaBiS₂ absorber with varied HTLs to improve lead-free photovoltaic stability & efficiency.

## 📁 Repository Contents
- SCAPS simulation files
- Machine learning datasets & training notebooks
- Python scripts for feature extraction & prediction
- Result figures and plots
- Reproducibility documentation

## 🧪 Tools Used
- SCAPS-1D
- Python (NumPy, Pandas, Sklearn, Matplotlib)
- Origin / Matlab for visualization
- ML model training and prediction

## Goal
To optimize NaBiS₂-based eco-friendly solar cells and analyze performance
variation using different HTLs through both numerical simulation & ML prediction.
