# NaBiS2-LeadFree-SolarCell-ML-Numerical-Analysis
Numerical and machine-learning based performance analysis of NaBiS₂ lead-free solar cells with different HTLs using SCAPS-1D simulation. The repository includes simulation data, ML prediction codes, training notebooks, result plots, and documentation for reproducibility and further enhancement of PV efficiency studies.
# NaBiS2 Lead-Free Solar Cells Numerical + ML Analysis

### 🔬 Research Focus
Numerical SCAPS-1D based device simulation and ML-driven performance
prediction of NaBiS₂ absorber with varied hole transport layers (HTLs)
to improve lead-free photovoltaic stability & efficiency.

### 📁 Repository Highlights
- SCAPS simulation model files
- Dataset used for training ML models
- Machine learning Jupyter notebooks & scripts
- Result graphs & high-resolution research figures
- Reproducibility documentation for future studies

### 🧪 Tools Used
- SCAPS-1D
- Python (NumPy, Pandas, Sklearn)
- Origin / Matlab for visualization
- Machine Learning (Regression + Feature Mapping)

### Research Goal
To optimize NaBiS₂-based eco-friendly solar cells and analyze performance
variation using different HTLs through both numerical simulation & ML prediction.
